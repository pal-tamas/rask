# IDeviceOrientation

> Gyroscope/compass tilt (alpha/beta/gamma) pushed to a callback.

- **Wraps:** Device Orientation events
- **MDN:** [Device orientation events](https://developer.mozilla.org/en-US/docs/Web/API/Device_orientation_events)
- **Home:** `Rask.Core.Browser` (all hosts)
- **Shape:** subscription (pushes to a callback)
- **Availability:** Web/Server ✅ · PWA/WASM ✅

iOS requires a gesture-triggered permission grant.
