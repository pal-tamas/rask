# IBadge

> Set/clear the count on the installed app icon.

- **Wraps:** Badging API
- **MDN:** [Badging API](https://developer.mozilla.org/en-US/docs/Web/API/Badging_API)
- **Home:** `Rask.Core.Browser` (all hosts)
- **Shape:** one-shot
- **Availability:** Web/Server ✅ · PWA/WASM ✅

`setAppBadge` needs an installed PWA instance, and the exact rendering is platform-dependent — treat the badge
as a hint, not a guaranteed surface.
